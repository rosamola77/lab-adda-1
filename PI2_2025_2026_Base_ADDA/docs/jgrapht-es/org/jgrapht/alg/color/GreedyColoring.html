Package org.jgrapht.alg.color

Class GreedyColoring<V,E>

Type Parameters:
V - el tipo del vértice
E - el tipo de la arista
public class GreedyColoring<V,E>

GreedyColoring asigna colores a los vértices de forma que ningún par de vértices adyacentes tenga el mismo color. Usa un algoritmo voraz (greedy).

Métodos Principales

  • getColoring() - Devuelve el coloreado como un objeto Coloring

Ejemplo de Uso

Graph<String, DefaultEdge> grafo = new SimpleGraph<>(DefaultEdge.class);

// Crear un pentágono
Graphs.addEdgeWithVertices(grafo, "A", "B");
Graphs.addEdgeWithVertices(grafo, "B", "C");
Graphs.addEdgeWithVertices(grafo, "C", "D");
Graphs.addEdgeWithVertices(grafo, "D", "E");
Graphs.addEdgeWithVertices(grafo, "E", "A");

// Aplicar coloreado
GreedyColoring<String, DefaultEdge> coloreo = new GreedyColoring<>(grafo);
Coloring<String> resultado = coloreo.getColoring();

System.out.println("Colores necesarios: " + resultado.getNumberColors());
Map<String, Integer> colores = resultado.getColors();
for (String v : grafo.vertexSet()) {
    System.out.println(v + " → color " + colores.get(v));
}

💡 Tip: El algoritmo greedy no siempre encuentra el número cromático óptimo, pero es eficiente.
