Package org.jgrapht.alg.spanning

Class KruskalMinimumSpanningTree<V,E>

Type Parameters:
V - el tipo del vértice
E - el tipo de la arista
public class KruskalMinimumSpanningTree<V,E>

KruskalMinimumSpanningTree implementa el algoritmo de Kruskal para encontrar el árbol de expansión mínima (MST) de un grafo no dirigido ponderado.

Métodos Principales

  • getSpanningTree() - Devuelve el MST como un SpanningTree

Ejemplo de Uso

Graph<String, DefaultWeightedEdge> grafo = 
    new SimpleWeightedGraph<>(DefaultWeightedEdge.class);

Graphs.addEdgeWithVertices(grafo, "A", "B", 4);
Graphs.addEdgeWithVertices(grafo, "A", "C", 2);
Graphs.addEdgeWithVertices(grafo, "B", "C", 1);
Graphs.addEdgeWithVertices(grafo, "B", "D", 5);
Graphs.addEdgeWithVertices(grafo, "C", "D", 3);

// Calcular MST
KruskalMinimumSpanningTree<String, DefaultWeightedEdge> kruskal = 
    new KruskalMinimumSpanningTree<>(grafo);

SpanningTree<DefaultWeightedEdge> mst = kruskal.getSpanningTree();

System.out.println("Peso total del MST: " + mst.getWeight());
System.out.println("Aristas del MST: " + mst.getEdges());
