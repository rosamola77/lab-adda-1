Class KruskalMinimumSpanningTree<V,E>

public class KruskalMinimumSpanningTree<V,E>
Algoritmo de Kruskal para árbol de expansión mínima (MST).

Métodos:

  • getSpanningTree() - Devuelve el MST

Ejemplo:
KruskalMinimumSpanningTree<String, DefaultWeightedEdge> kruskal = new KruskalMinimumSpanningTree<>(grafo);
SpanningTree<DefaultWeightedEdge> mst = kruskal.getSpanningTree();
