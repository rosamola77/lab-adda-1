Package org.jgrapht.alg.shortestpath

Class DijkstraShortestPath<V,E>

Type Parameters:
V - el tipo del vértice
E - el tipo de la arista
public class DijkstraShortestPath<V,E>

DijkstraShortestPath implementa el algoritmo de Dijkstra para encontrar el camino más corto entre dos vértices en un grafo ponderado con pesos no negativos.

Métodos Principales

  • getPath(source, sink) - Devuelve el camino más corto entre origen y destino
  • getPathWeight(source, sink) - Devuelve solo el peso total del camino
  • getPaths(source) - Devuelve árbol de caminos desde un origen

Ejemplo de Uso

Graph<String, DefaultWeightedEdge> grafo = 
    new SimpleWeightedGraph<>(DefaultWeightedEdge.class);

Graphs.addEdgeWithVertices(grafo, "Madrid", "Barcelona", 621);
Graphs.addEdgeWithVertices(grafo, "Madrid", "Valencia", 352);
Graphs.addEdgeWithVertices(grafo, "Barcelona", "Valencia", 349);

// Crear instancia de Dijkstra
DijkstraShortestPath<String, DefaultWeightedEdge> dijkstra = 
    new DijkstraShortestPath<>(grafo);

// Obtener camino más corto
GraphPath<String, DefaultWeightedEdge> camino = 
    dijkstra.getPath("Madrid", "Barcelona");

if (camino != null) {
    System.out.println("Ruta: " + camino.getVertexList());
    System.out.println("Distancia: " + camino.getWeight());
}

⚠️ Importante: Solo funciona con pesos no negativos. Para pesos negativos usar BellmanFordShortestPath.
