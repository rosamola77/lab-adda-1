Class DijkstraShortestPath<V,E>

public class DijkstraShortestPath<V,E>
Algoritmo de Dijkstra para camino más corto (pesos no negativos).

Métodos:

  • getPath(source, sink) - Devuelve el camino más corto
  • getPathWeight(source, sink) - Devuelve el peso del camino

Ejemplo:
DijkstraShortestPath<String, DefaultWeightedEdge> dijkstra = new DijkstraShortestPath<>(grafo);
GraphPath<String, DefaultWeightedEdge> camino = dijkstra.getPath("A", "Z");
