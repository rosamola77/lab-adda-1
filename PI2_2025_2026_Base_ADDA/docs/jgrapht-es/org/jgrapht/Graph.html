Package org.jgrapht

Interface Graph<V,E>

Type Parameters:
V - el tipo del vértice
E - el tipo de la arista
public interface Graph<V,E>

Graph<V, E> es la interfaz principal de JGraphT. Define todas las operaciones básicas que se pueden realizar sobre un grafo, independientemente de su tipo (dirigido, no dirigido, ponderado, etc.).

Parámetros de tipo:

  • V: Tipo del vértice (ej: String, Integer, objetos personalizados)
  • E: Tipo de la arista (ej: DefaultEdge, DefaultWeightedEdge)

💡 Tip: La interfaz Graph no se instancia directamente. Usa implementaciones como SimpleGraph, SimpleDirectedGraph, SimpleWeightedGraph, etc.

Operaciones con Vértices

  • addVertex(V v) - Añade un vértice al grafo. Devuelve true si el vértice fue añadido.
  • removeVertex(V v) - Elimina un vértice y todas sus aristas incidentes.
  • containsVertex(V v) - Comprueba si el vértice existe en el grafo.
  • vertexSet() - Devuelve el conjunto de todos los vértices del grafo.

Operaciones con Aristas

  • addEdge(V source, V target) - Crea una arista entre dos vértices.
  • removeEdge(V source, V target) - Elimina la arista entre dos vértices.
  • containsEdge(V source, V target) - Comprueba si existe una arista entre dos vértices.
  • getEdge(V source, V target) - Devuelve la arista entre dos vértices.
  • edgeSet() - Devuelve el conjunto de todas las aristas del grafo.
  • edgesOf(V v) - Devuelve todas las aristas conectadas a un vértice.
  • getAllEdges(V source, V target) - Devuelve todas las aristas entre dos vértices.
  • incomingEdgesOf(V v) - Para grafos dirigidos: aristas entrantes.
  • outgoingEdgesOf(V v) - Para grafos dirigidos: aristas salientes.

Información del Grafo

  • degreeOf(V v) - Devuelve el grado de un vértice.
  • inDegreeOf(V v) - Grado de entrada (grafos dirigidos).
  • outDegreeOf(V v) - Grado de salida (grafos dirigidos).
  • getEdgeSource(E e) - Obtiene el vértice origen de una arista.
  • getEdgeTarget(E e) - Obtiene el vértice destino de una arista.
  • getEdgeWeight(E e) - Obtiene el peso de una arista.
  • setEdgeWeight(E e, double weight) - Establece el peso de una arista.
  • getType() - Devuelve información sobre el tipo del grafo.

Ejemplo de Uso

Graph<String, DefaultEdge> g = new SimpleGraph<>(DefaultEdge.class);
g.addVertex("Madrid");
g.addVertex("Barcelona");
g.addEdge("Madrid", "Barcelona");
System.out.println("Vértices: " + g.vertexSet());
System.out.println("Grado de Madrid: " + g.degreeOf("Madrid"));
