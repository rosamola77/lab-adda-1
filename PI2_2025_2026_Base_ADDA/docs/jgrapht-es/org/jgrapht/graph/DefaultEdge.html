Package org.jgrapht.graph

Class DefaultEdge

public class DefaultEdge extends Object

DefaultEdge es la implementación por defecto de una arista sin peso.

Uso típico:

  • Para grafos no ponderados (SimpleGraph, SimpleDirectedGraph)
  • Cuando no necesitas almacenar información adicional en las aristas

Ejemplo de Uso

// Crear grafo con DefaultEdge
Graph<String, DefaultEdge> g = new SimpleGraph<>(DefaultEdge.class);
g.addVertex("A");
g.addVertex("B");
DefaultEdge e = g.addEdge("A", "B");

// Obtener extremos de la arista
String origen = g.getEdgeSource(e);   // "A"
String destino = g.getEdgeTarget(e);  // "B"
