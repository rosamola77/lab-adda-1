Package org.jgrapht.graph

Class SimpleWeightedGraph<V,E>

Type Parameters:
V - el tipo del vértice
E - el tipo de la arista
public class SimpleWeightedGraph<V,E> extends SimpleGraph<V,E>

SimpleWeightedGraph es un grafo simple no dirigido ponderado.

Características:

  • No dirigido: las aristas no tienen dirección
  • Ponderado: las aristas tienen un peso asociado (double)
  • Sin bucles ni aristas múltiples

Ejemplo de Uso

// Crear grafo ponderado
Graph<String, DefaultWeightedEdge> wg = 
    new SimpleWeightedGraph<>(DefaultWeightedEdge.class);

// Añadir aristas con peso
Graphs.addEdgeWithVertices(wg, "Madrid", "Barcelona", 621.0);
Graphs.addEdgeWithVertices(wg, "Madrid", "Valencia", 352.0);

// Consultar peso
DefaultWeightedEdge e = wg.getEdge("Madrid", "Barcelona");
double distancia = wg.getEdgeWeight(e);  // 621.0

// Modificar peso
wg.setEdgeWeight(e, 625.0);
