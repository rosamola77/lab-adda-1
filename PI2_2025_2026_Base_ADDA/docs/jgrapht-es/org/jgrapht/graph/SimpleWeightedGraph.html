📖 Descripción

Graph<V, E> es la interfaz principal de JGraphT. Define todas las operaciones básicas que se pueden realizar sobre un grafo, independientemente de su tipo (dirigido, no dirigido, ponderado, etc.).

  • V: Tipo del vértice (ej: String, Integer, objetos personalizados)
  • E: Tipo de la arista (ej: DefaultEdge, DefaultWeightedEdge)
💡 Tip: La interfaz Graph no se instancia directamente. Usa implementaciones como SimpleGraph, SimpleDirectedGraph, SimpleWeightedGraph, etc.

🔧 Métodos Principales

Operaciones con Vértices

addVertex(V v)

boolean addVertex(V v)

Añade un vértice al grafo. Devuelve true si el vértice fue añadido, false si ya existía.

Graph<String, DefaultEdge> g = new SimpleGraph<>(DefaultEdge.class);
boolean added = g.addVertex("Madrid");    // true
boolean again = g.addVertex("Madrid");    // false (ya existe)

removeVertex(V v)

boolean removeVertex(V v)

Elimina un vértice y todas sus aristas incidentes. Devuelve true si existía.

g.removeVertex("Madrid");  // Elimina el vértice y sus conexiones

containsVertex(V v)

boolean containsVertex(V v)

Comprueba si el vértice existe en el grafo.

if (g.containsVertex("Madrid")) {
    System.out.println("Madrid está en el grafo");
}

vertexSet()

Set<V> vertexSet()

Devuelve el conjunto de todos los vértices del grafo.

Set<String> vertices = g.vertexSet();
System.out.println("Número de vértices: " + vertices.size());

// Iterar sobre vértices
for (String v : g.vertexSet()) {
    System.out.println("Vértice: " + v);
}

Operaciones con Aristas

addEdge(V source, V target)

E addEdge(V sourceVertex, V targetVertex)

Crea una arista entre dos vértices. Ambos vértices deben existir previamente.

g.addVertex("Madrid");
g.addVertex("Barcelona");
DefaultEdge e = g.addEdge("Madrid", "Barcelona");
⚠️ Importante: Si los vértices no existen, se lanzará una excepción. Usa Graphs.addEdgeWithVertices() para añadir arista y vértices en una sola operación.

removeEdge(V source, V target)

E removeEdge(V sourceVertex, V targetVertex)

Elimina la arista entre dos vértices. Devuelve la arista eliminada o null.

DefaultEdge removed = g.removeEdge("Madrid", "Barcelona");

removeEdge(E e)

boolean removeEdge(E e)

Elimina una arista específica del grafo.

DefaultEdge e = g.getEdge("Madrid", "Barcelona");
g.removeEdge(e);

containsEdge(V source, V target)

boolean containsEdge(V sourceVertex, V targetVertex)

Comprueba si existe una arista entre dos vértices.

if (g.containsEdge("Madrid", "Barcelona")) {
    System.out.println("Hay conexión directa");
}

getEdge(V source, V target)

E getEdge(V sourceVertex, V targetVertex)

Devuelve la arista entre dos vértices, o null si no existe.

DefaultEdge e = g.getEdge("Madrid", "Barcelona");
if (e != null) {
    System.out.println("Arista encontrada: " + e);
}

edgeSet()

Set<E> edgeSet()

Devuelve el conjunto de todas las aristas del grafo.

Set<DefaultEdge> aristas = g.edgeSet();
System.out.println("Número de aristas: " + aristas.size());

edgesOf(V v)

Set<E> edgesOf(V vertex)

Devuelve todas las aristas conectadas a un vértice.

Set<DefaultEdge> aristasDeMadrid = g.edgesOf("Madrid");
System.out.println("Madrid tiene " + aristasDeMadrid.size() + " conexiones");

getAllEdges(V source, V target)

Set<E> getAllEdges(V sourceVertex, V targetVertex)

Devuelve todas las aristas entre dos vértices. Útil en multigrafos donde puede haber múltiples aristas.

Set<DefaultEdge> todasAristas = g.getAllEdges("Madrid", "Barcelona");
System.out.println("Aristas entre Madrid y Barcelona: " + todasAristas.size());

incomingEdgesOf(V v) / outgoingEdgesOf(V v)

Set<E> incomingEdgesOf(V vertex)
Set<E> outgoingEdgesOf(V vertex)

Para grafos dirigidos: aristas entrantes y salientes de un vértice.

Graph<String, DefaultEdge> dg = new SimpleDirectedGraph<>(DefaultEdge.class);
// ... añadir vértices y aristas ...
Set<DefaultEdge> entrantes = dg.incomingEdgesOf("Madrid");  // Aristas que llegan a Madrid
Set<DefaultEdge> salientes = dg.outgoingEdgesOf("Madrid");  // Aristas que salen de Madrid

containsEdge(E e)

boolean containsEdge(E e)

Comprueba si una arista específica existe en el grafo.

DefaultEdge e = g.getEdge("Madrid", "Barcelona");
if (g.containsEdge(e)) {
    System.out.println("La arista existe");
}

removeAllEdges(V source, V target)

Set<E> removeAllEdges(V sourceVertex, V targetVertex)

Elimina todas las aristas entre dos vértices. Devuelve el conjunto de aristas eliminadas.

Set<DefaultEdge> eliminadas = g.removeAllEdges("Madrid", "Barcelona");

removeAllEdges(Collection)

boolean removeAllEdges(Collection<? extends E> edges)

Elimina una colección de aristas del grafo.

Set<DefaultEdge> aristasAEliminar = new HashSet<>();
// ... añadir aristas a eliminar ...
g.removeAllEdges(aristasAEliminar);

removeAllVertices(Collection)

boolean removeAllVertices(Collection<? extends V> vertices)

Elimina una colección de vértices y todas sus aristas incidentes.

List<String> ciudadesAEliminar = Arrays.asList("Madrid", "Barcelona");
g.removeAllVertices(ciudadesAEliminar);

Información del Grafo

degreeOf(V v)

int degreeOf(V vertex)

Devuelve el grado de un vértice (número de aristas incidentes).

int grado = g.degreeOf("Madrid");
System.out.println("Grado de Madrid: " + grado);
📝 Nota: En grafos dirigidos, usa inDegreeOf() y outDegreeOf() para obtener el grado de entrada y salida respectivamente.

inDegreeOf(V v) / outDegreeOf(V v)

int inDegreeOf(V vertex)
int outDegreeOf(V vertex)

Para grafos dirigidos: grado de entrada (aristas que llegan) y grado de salida (aristas que salen).

Graph<String, DefaultEdge> dg = new SimpleDirectedGraph<>(DefaultEdge.class);
// ... añadir vértices y aristas ...
int entradas = dg.inDegreeOf("Madrid");   // Aristas que llegan a Madrid
int salidas = dg.outDegreeOf("Madrid");   // Aristas que salen de Madrid

getEdgeSource(E e) / getEdgeTarget(E e)

V getEdgeSource(E e)
V getEdgeTarget(E e)

Obtiene los vértices origen y destino de una arista.

DefaultEdge e = g.getEdge("Madrid", "Barcelona");
String origen = g.getEdgeSource(e);   // "Madrid"
String destino = g.getEdgeTarget(e);  // "Barcelona"

getEdgeWeight(E e) / setEdgeWeight(E e, double weight)

double getEdgeWeight(E e)
void setEdgeWeight(E e, double weight)

Obtiene o establece el peso de una arista (solo en grafos ponderados).

Graph<String, DefaultWeightedEdge> wg = 
    new SimpleWeightedGraph<>(DefaultWeightedEdge.class);
wg.addVertex("Madrid");
wg.addVertex("Barcelona");
DefaultWeightedEdge e = wg.addEdge("Madrid", "Barcelona");
wg.setEdgeWeight(e, 621.0);  // Distancia en km
double peso = wg.getEdgeWeight(e);  // 621.0

setEdgeWeight(V source, V target, double weight)

void setEdgeWeight(V sourceVertex, V targetVertex, double weight)

Establece el peso de la arista entre dos vértices directamente (sin obtener la arista).

wg.setEdgeWeight("Madrid", "Barcelona", 621.0);  // Más directo

getType()

GraphType getType()

Devuelve información sobre el tipo del grafo (dirigido, ponderado, permite bucles, etc.).

GraphType tipo = g.getType();
System.out.println("¿Dirigido? " + tipo.isDirected());
System.out.println("¿Ponderado? " + tipo.isWeighted());
System.out.println("¿Permite bucles? " + tipo.isAllowingSelfLoops());
System.out.println("¿Permite múltiples aristas? " + tipo.isAllowingMultipleEdges());

getVertexSupplier() / getEdgeSupplier()

Supplier<V> getVertexSupplier()
Supplier<E> getEdgeSupplier()

Devuelve los proveedores (suppliers) para crear nuevos vértices y aristas automáticamente.

Supplier<String> vertexSupplier = g.getVertexSupplier();
Supplier<DefaultEdge> edgeSupplier = g.getEdgeSupplier();

💡 Ejemplos Completos

Ejemplo 1: Crear un grafo de ciudades

import org.jgrapht.*;
import org.jgrapht.graph.*;

public class EjemploGrafoCiudades {
    public static void main(String[] args) {
        // Crear grafo no dirigido
        Graph<String, DefaultEdge> grafo = new SimpleGraph<>(DefaultEdge.class);
        
        // Añadir ciudades
        grafo.addVertex("Madrid");
        grafo.addVertex("Barcelona");
        grafo.addVertex("Valencia");
        grafo.addVertex("Sevilla");
        
        // Añadir conexiones
        grafo.addEdge("Madrid", "Barcelona");
        grafo.addEdge("Madrid", "Valencia");
        grafo.addEdge("Madrid", "Sevilla");
        grafo.addEdge("Barcelona", "Valencia");
        
        // Consultas
        System.out.println("Ciudades: " + grafo.vertexSet());
        System.out.println("Conexiones: " + grafo.edgeSet().size());
        System.out.println("Grado de Madrid: " + grafo.degreeOf("Madrid"));
        
        // Vecinos de Madrid
        for (DefaultEdge e : grafo.edgesOf("Madrid")) {
            String origen = grafo.getEdgeSource(e);
            String destino = grafo.getEdgeTarget(e);
            String vecino = origen.equals("Madrid") ? destino : origen;
            System.out.println("Madrid conecta con: " + vecino);
        }
    }
}

Ejemplo 2: Grafo ponderado con distancias

import org.jgrapht.*;
import org.jgrapht.graph.*;

public class EjemploGrafoPonderado {
    public static void main(String[] args) {
        Graph<String, DefaultWeightedEdge> grafo = 
            new SimpleWeightedGraph<>(DefaultWeightedEdge.class);
        
        grafo.addVertex("Madrid");
        grafo.addVertex("Barcelona");
        grafo.addVertex("Valencia");
        
        DefaultWeightedEdge e1 = grafo.addEdge("Madrid", "Barcelona");
        grafo.setEdgeWeight(e1, 621);
        
        DefaultWeightedEdge e2 = grafo.addEdge("Madrid", "Valencia");
        grafo.setEdgeWeight(e2, 352);
        
        DefaultWeightedEdge e3 = grafo.addEdge("Barcelona", "Valencia");
        grafo.setEdgeWeight(e3, 349);
        
        // Consultar pesos
        for (DefaultWeightedEdge e : grafo.edgeSet()) {
            System.out.println(grafo.getEdgeSource(e) + " - " + 
                             grafo.getEdgeTarget(e) + ": " + 
                             grafo.getEdgeWeight(e) + " km");
        }
    }
}
