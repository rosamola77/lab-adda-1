org.jgrapht.graph
Class SimpleWeightedGraph<V,E>

public class SimpleWeightedGraph<V,E> extends SimpleGraph<V,E>
Grafo simple no dirigido ponderado (aristas con peso).

Características: No dirigido, ponderado (peso double en aristas).

Ejemplo:
Graph<String, DefaultWeightedEdge> wg = new SimpleWeightedGraph<>(DefaultWeightedEdge.class);
Graphs.addEdgeWithVertices(wg, "A", "B", 5.0);
