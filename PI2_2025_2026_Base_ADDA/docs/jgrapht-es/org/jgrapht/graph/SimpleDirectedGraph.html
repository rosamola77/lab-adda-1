Package org.jgrapht.graph

Class SimpleDirectedGraph<V,E>

Type Parameters:
V - el tipo del vértice
E - el tipo de la arista
public class SimpleDirectedGraph<V,E> extends AbstractBaseGraph<V,E>

SimpleDirectedGraph es un grafo simple dirigido sin bucles ni aristas múltiples.

Características:

  • Dirigido: las aristas tienen dirección (origen → destino)
  • Sin bucles: un vértice no puede conectarse consigo mismo
  • Sin aristas múltiples: solo puede haber una arista en cada dirección entre dos vértices

Ejemplo de Uso

// Crear grafo dirigido
Graph<String, DefaultEdge> dg = new SimpleDirectedGraph<>(DefaultEdge.class);

// Añadir aristas dirigidas
Graphs.addEdgeWithVertices(dg, "A", "B");  // A → B
Graphs.addEdgeWithVertices(dg, "B", "C");  // B → C

// Consultar grados
int entrada = dg.inDegreeOf("B");   // 1 (arista desde A)
int salida = dg.outDegreeOf("B");   // 1 (arista hacia C)

// Sucesores y predecesores
List<String> sucesores = Graphs.successorListOf(dg, "A");     // [B]
List<String> predecesores = Graphs.predecessorListOf(dg, "C"); // [B]
