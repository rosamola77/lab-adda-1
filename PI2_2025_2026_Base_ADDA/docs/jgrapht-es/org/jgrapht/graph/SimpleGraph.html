Package org.jgrapht.graph

Class SimpleGraph<V,E>

Type Parameters:
V - el tipo del vértice
E - el tipo de la arista
public class SimpleGraph<V,E> extends AbstractBaseGraph<V,E>

SimpleGraph es un grafo simple no dirigido sin bucles ni aristas múltiples.

Características:

  • No dirigido: las aristas no tienen dirección
  • Sin bucles: un vértice no puede conectarse consigo mismo
  • Sin aristas múltiples: solo puede haber una arista entre dos vértices

Ejemplo de Uso

// Crear grafo simple
Graph<String, DefaultEdge> g = new SimpleGraph<>(DefaultEdge.class);

// Añadir vértices
g.addVertex("A");
g.addVertex("B");
g.addVertex("C");

// Añadir aristas
g.addEdge("A", "B");
g.addEdge("B", "C");

// O usar Graphs.addEdgeWithVertices para crear vértices automáticamente
Graphs.addEdgeWithVertices(g, "C", "D");
