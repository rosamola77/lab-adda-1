Package org.jgrapht.graph

Class DefaultWeightedEdge

public class DefaultWeightedEdge extends DefaultEdge

DefaultWeightedEdge es la implementación por defecto de una arista con peso.

Uso típico:

  • Para grafos ponderados (SimpleWeightedGraph, SimpleDirectedWeightedGraph)
  • Almacena un peso de tipo double para cada arista

Ejemplo de Uso

// Crear grafo ponderado con DefaultWeightedEdge
Graph<String, DefaultWeightedEdge> wg = 
    new SimpleWeightedGraph<>(DefaultWeightedEdge.class);

wg.addVertex("Madrid");
wg.addVertex("Barcelona");
DefaultWeightedEdge e = wg.addEdge("Madrid", "Barcelona");
wg.setEdgeWeight(e, 621.0);  // Distancia en km

// Consultar peso
double peso = wg.getEdgeWeight(e);  // 621.0

// O usando Graphs para crear todo de una vez:
Graphs.addEdgeWithVertices(wg, "Madrid", "Valencia", 352.0);
