Package org.jgrapht

Class Graphs

public final class Graphs

Graphs es una clase de utilidades que proporciona métodos estáticos para realizar operaciones comunes sobre grafos de forma más cómoda.

💡 Tip: Todos los métodos de esta clase son static, por lo que se llaman directamente: Graphs.metodo(...)

Métodos Más Útiles

  • addEdgeWithVertices(g, source, target) - Añade una arista creando los vértices automáticamente si no existen. ¡El método más útil!
  • addEdgeWithVertices(g, source, target, weight) - Versión para grafos ponderados.
  • neighborListOf(g, vertex) - Devuelve una lista con todos los vecinos de un vértice.
  • neighborSetOf(g, vertex) - Similar pero devuelve un Set.
  • predecessorListOf(g, vertex) - En grafos dirigidos, vértices que apuntan al dado.
  • successorListOf(g, vertex) - En grafos dirigidos, vértices a los que apunta el dado.
  • getOppositeVertex(g, e, v) - Dado una arista y un vértice, devuelve el otro extremo.
  • addAllVertices(g, vertices) - Añade múltiples vértices de una colección.
  • addGraph(dest, source) - Copia todos los vértices y aristas de un grafo a otro.
  • addGraphReversed(dest, source) - Copia invirtiendo dirección de aristas.
  • testIncidence(g, e, v) - Comprueba si una arista es incidente a un vértice.
  • undirectedGraph(g) - Devuelve una vista no dirigida de un grafo dirigido.
  • removeVertexAndPreserveConnectivity(g, v) - Elimina vértice conectando predecesores con sucesores.

Ejemplo de Uso

Graph<String, DefaultEdge> g = new SimpleGraph<>(DefaultEdge.class);

// Forma rápida: una línea por arista (crea vértices automáticamente)
Graphs.addEdgeWithVertices(g, "A", "B");
Graphs.addEdgeWithVertices(g, "B", "C");

// Obtener vecinos
List<String> vecinos = Graphs.neighborListOf(g, "B");
// Resultado: [A, C]
