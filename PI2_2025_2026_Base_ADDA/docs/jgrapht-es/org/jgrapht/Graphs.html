Class Graphs

public final class Graphs
Clase de utilidades con métodos estáticos para operaciones comunes sobre grafos.

Métodos más útiles:

  • addEdgeWithVertices(g, source, target) - Añade arista creando vértices automáticamente
  • addEdgeWithVertices(g, source, target, weight) - Versión con peso
  • neighborListOf(g, vertex) - Lista de vecinos de un vértice
  • neighborSetOf(g, vertex) - Set de vecinos
  • predecessorListOf(g, vertex) - Predecesores (grafos dirigidos)
  • successorListOf(g, vertex) - Sucesores (grafos dirigidos)
  • getOppositeVertex(g, e, v) - Otro extremo de una arista
  • addAllVertices(g, vertices) - Añade múltiples vértices
  • addGraph(dest, source) - Copia un grafo a otro

Ejemplo:
Graphs.addEdgeWithVertices(g, "A", "B");
List<String> vecinos = Graphs.neighborListOf(g, "A");
