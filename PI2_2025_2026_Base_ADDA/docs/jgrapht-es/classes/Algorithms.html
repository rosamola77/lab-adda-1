📖 Descripción General

JGraphT incluye implementaciones eficientes de los algoritmos más importantes de teoría de grafos. Esta página documenta los algoritmos más utilizados en el curso de ADDA.

🛤️ Caminos Mínimos

DijkstraShortestPath

org.jgrapht.alg.shortestpath.DijkstraShortestPath

Implementación del algoritmo de Dijkstra para encontrar el camino más corto entre dos vértices en un grafo ponderado con pesos no negativos.

DijkstraShortestPath<V, E>(Graph<V, E> graph)

Métodos principales:

  • getPath(V source, V sink) — Devuelve el camino más corto entre origen y destino
  • getPathWeight(V source, V sink) — Devuelve solo el peso total del camino
  • getPaths(V source) — Devuelve árbol de caminos desde un origen
import org.jgrapht.*;
import org.jgrapht.graph.*;
import org.jgrapht.alg.shortestpath.DijkstraShortestPath;

public class EjemploDijkstra {
    public static void main(String[] args) {
        // Crear grafo ponderado
        Graph<String, DefaultWeightedEdge> grafo = 
            new SimpleWeightedGraph<>(DefaultWeightedEdge.class);
        
        // Añadir ciudades y distancias
        Graphs.addEdgeWithVertices(grafo, "Madrid", "Barcelona", 621);
        Graphs.addEdgeWithVertices(grafo, "Madrid", "Valencia", 352);
        Graphs.addEdgeWithVertices(grafo, "Barcelona", "Valencia", 349);
        Graphs.addEdgeWithVertices(grafo, "Valencia", "Sevilla", 654);
        Graphs.addEdgeWithVertices(grafo, "Madrid", "Sevilla", 538);
        
        // Crear instancia de Dijkstra
        DijkstraShortestPath<String, DefaultWeightedEdge> dijkstra = 
            new DijkstraShortestPath<>(grafo);
        
        // Obtener camino más corto Barcelona → Sevilla
        GraphPath<String, DefaultWeightedEdge> camino = 
            dijkstra.getPath("Barcelona", "Sevilla");
        
        if (camino != null) {
            System.out.println("Camino: " + camino.getVertexList());
            System.out.println("Distancia total: " + camino.getWeight() + " km");
            System.out.println("Número de aristas: " + camino.getLength());
        }
    }
}
📝 Nota: El objeto GraphPath contiene:
  • getVertexList() — Lista ordenada de vértices del camino
  • getEdgeList() — Lista de aristas del camino
  • getWeight() — Peso total del camino
  • getLength() — Número de aristas

BellmanFordShortestPath

org.jgrapht.alg.shortestpath.BellmanFordShortestPath

Alternativa a Dijkstra que permite pesos negativos (pero no ciclos negativos). Más lento que Dijkstra: O(V·E) vs O((V+E)·log V). 

import org.jgrapht.alg.shortestpath.BellmanFordShortestPath;

BellmanFordShortestPath<String, DefaultWeightedEdge> bellmanFord = 
    new BellmanFordShortestPath<>(grafo);
GraphPath<String, DefaultWeightedEdge> camino = 
    bellmanFord.getPath("A", "Z");

FloydWarshallShortestPaths

org.jgrapht.alg.shortestpath.FloydWarshallShortestPaths

Calcula los caminos más cortos entre todos los pares de vértices. Útil cuando necesitas consultar múltiples caminos. 

import org.jgrapht.alg.shortestpath.FloydWarshallShortestPaths;

FloydWarshallShortestPaths<String, DefaultWeightedEdge> floyd = 
    new FloydWarshallShortestPaths<>(grafo);

// Consultar cualquier par de vértices
double distancia = floyd.getPathWeight("Madrid", "Barcelona");
GraphPath<String, DefaultWeightedEdge> camino = floyd.getPath("Madrid", "Barcelona");

🌲 Árbol de Expansión Mínima (MST)

KruskalMinimumSpanningTree

org.jgrapht.alg.spanning.KruskalMinimumSpanningTree

Implementación del algoritmo de Kruskal para encontrar el árbol de expansión mínima de un grafo no dirigido ponderado. 

import org.jgrapht.*;
import org.jgrapht.graph.*;
import org.jgrapht.alg.spanning.KruskalMinimumSpanningTree;

public class EjemploKruskal {
    public static void main(String[] args) {
        Graph<String, DefaultWeightedEdge> grafo = 
            new SimpleWeightedGraph<>(DefaultWeightedEdge.class);
        
        Graphs.addEdgeWithVertices(grafo, "A", "B", 4);
        Graphs.addEdgeWithVertices(grafo, "A", "C", 2);
        Graphs.addEdgeWithVertices(grafo, "B", "C", 1);
        Graphs.addEdgeWithVertices(grafo, "B", "D", 5);
        Graphs.addEdgeWithVertices(grafo, "C", "D", 3);
        
        // Calcular MST
        KruskalMinimumSpanningTree<String, DefaultWeightedEdge> kruskal = 
            new KruskalMinimumSpanningTree<>(grafo);
        
        SpanningTree<DefaultWeightedEdge> mst = kruskal.getSpanningTree();
        
        System.out.println("Peso total del MST: " + mst.getWeight());
        System.out.println("Aristas del MST:");
        for (DefaultWeightedEdge e : mst.getEdges()) {
            System.out.println("  " + grafo.getEdgeSource(e) + " - " + 
                             grafo.getEdgeTarget(e) + " (peso: " + 
                             grafo.getEdgeWeight(e) + ")");
        }
    }
}

PrimMinimumSpanningTree

org.jgrapht.alg.spanning.PrimMinimumSpanningTree

Alternativa a Kruskal usando el algoritmo de Prim. Mismo resultado, diferente estrategia. 

import org.jgrapht.alg.spanning.PrimMinimumSpanningTree;

PrimMinimumSpanningTree<String, DefaultWeightedEdge> prim = 
    new PrimMinimumSpanningTree<>(grafo);
SpanningTree<DefaultWeightedEdge> mst = prim.getSpanningTree();

🎨 Coloreado de Grafos

GreedyColoring

org.jgrapht.alg.color.GreedyColoring

Asigna colores a los vértices de forma que ningún par de vértices adyacentes tenga el mismo color. Usa un algoritmo voraz (greedy). 

import org.jgrapht.*;
import org.jgrapht.graph.*;
import org.jgrapht.alg.color.GreedyColoring;
import org.jgrapht.alg.interfaces.VertexColoringAlgorithm.Coloring;

public class EjemploColoreado {
    public static void main(String[] args) {
        Graph<String, DefaultEdge> grafo = new SimpleGraph<>(DefaultEdge.class);
        
        // Crear un grafo (pentágono)
        Graphs.addEdgeWithVertices(grafo, "A", "B");
        Graphs.addEdgeWithVertices(grafo, "B", "C");
        Graphs.addEdgeWithVertices(grafo, "C", "D");
        Graphs.addEdgeWithVertices(grafo, "D", "E");
        Graphs.addEdgeWithVertices(grafo, "E", "A");
        
        // Aplicar coloreado
        GreedyColoring<String, DefaultEdge> coloreo = 
            new GreedyColoring<>(grafo);
        Coloring<String> resultado = coloreo.getColoring();
        
        System.out.println("Número cromático: " + resultado.getNumberColors());
        System.out.println("Colores asignados:");
        for (String vertice : grafo.vertexSet()) {
            System.out.println("  " + vertice + ": color " + 
                             resultado.getColors().get(vertice));
        }
    }
}
💡 Tip: El número cromático es el mínimo número de colores necesarios. El algoritmo greedy no siempre encuentra el óptimo, pero es eficiente.

🔄 Recorridos (BFS y DFS)

BreadthFirstIterator

org.jgrapht.traverse.BreadthFirstIterator

Recorre el grafo en anchura (BFS) desde un vértice inicial.

import org.jgrapht.traverse.BreadthFirstIterator;
import java.util.Iterator;

Iterator<String> bfs = new BreadthFirstIterator<>(grafo, "A");
System.out.println("Recorrido BFS desde A:");
while (bfs.hasNext()) {
    String vertice = bfs.next();
    System.out.println("  Visitando: " + vertice);
}

DepthFirstIterator

org.jgrapht.traverse.DepthFirstIterator

Recorre el grafo en profundidad (DFS) desde un vértice inicial.

import org.jgrapht.traverse.DepthFirstIterator;
import java.util.Iterator;

Iterator<String> dfs = new DepthFirstIterator<>(grafo, "A");
System.out.println("Recorrido DFS desde A:");
while (dfs.hasNext()) {
    String vertice = dfs.next();
    System.out.println("  Visitando: " + vertice);
}

🔗 Conectividad

ConnectivityInspector

org.jgrapht.alg.connectivity.ConnectivityInspector

Analiza la conectividad del grafo: componentes conexas, caminos existentes, etc.

import org.jgrapht.alg.connectivity.ConnectivityInspector;

ConnectivityInspector<String, DefaultEdge> inspector = 
    new ConnectivityInspector<>(grafo);

// ¿El grafo es conexo?
boolean esConexo = inspector.isConnected();
System.out.println("¿Grafo conexo? " + esConexo);

// ¿Existe camino entre dos vértices?
boolean hayRuta = inspector.pathExists("A", "Z");

// Obtener componentes conexas
Set<Set<String>> componentes = inspector.connectedSets();
System.out.println("Número de componentes: " + componentes.size());

🔁 Detección de Ciclos

CycleDetector

org.jgrapht.alg.cycle.CycleDetector

Detecta ciclos en grafos dirigidos.

import org.jgrapht.alg.cycle.CycleDetector;

Graph<String, DefaultEdge> grafoDirigido = 
    new SimpleDirectedGraph<>(DefaultEdge.class);
// ... añadir vértices y aristas ...

CycleDetector<String, DefaultEdge> detector = 
    new CycleDetector<>(grafoDirigido);

boolean tieneCiclos = detector.detectCycles();
System.out.println("¿Tiene ciclos? " + tieneCiclos);

// Vértices que participan en ciclos
Set<String> verticesEnCiclos = detector.findCycles();
System.out.println("Vértices en ciclos: " + verticesEnCiclos);

📊 Orden Topológico

TopologicalOrderIterator

org.jgrapht.traverse.TopologicalOrderIterator

Recorre un grafo dirigido acíclico (DAG) en orden topológico.

import org.jgrapht.traverse.TopologicalOrderIterator;

Graph<String, DefaultEdge> dag = new SimpleDirectedGraph<>(DefaultEdge.class);
Graphs.addEdgeWithVertices(dag, "Compilar", "Ejecutar");
Graphs.addEdgeWithVertices(dag, "Diseñar", "Compilar");
Graphs.addEdgeWithVertices(dag, "Diseñar", "Documentar");
Graphs.addEdgeWithVertices(dag, "Ejecutar", "Desplegar");
Graphs.addEdgeWithVertices(dag, "Documentar", "Desplegar");

TopologicalOrderIterator<String, DefaultEdge> topoIterator = 
    new TopologicalOrderIterator<>(dag);

System.out.println("Orden de ejecución:");
while (topoIterator.hasNext()) {
    System.out.println("  " + topoIterator.next());
}
