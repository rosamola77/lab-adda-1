📖 Introducción

JGraphT es una biblioteca Java gratuita y de código abierto que proporciona estructuras de datos y algoritmos para grafos de todo tipo. Es ampliamente utilizada en aplicaciones académicas e industriales para resolver problemas relacionados con teoría de grafos.

Esta documentación en español está diseñada específicamente para los estudiantes del curso de Análisis de Datos y Diseño de Algoritmos (ADDA) de la Universidad de Sevilla, con ejemplos prácticos y explicaciones didácticas.

📝 Nota: Esta documentación es material didáctico complementario. Para la documentación oficial completa en inglés, visita: https://jgrapht.org/javadoc/

🚀 Inicio Rápido

Ejemplo básico de creación y manipulación de un grafo:

import org.jgrapht.*;
import org.jgrapht.graph.*;

// 1. Crear un grafo simple no dirigido
Graph<String, DefaultEdge> grafo = new SimpleGraph<>(DefaultEdge.class);

// 2. Añadir vértices
grafo.addVertex("A");
grafo.addVertex("B");
grafo.addVertex("C");

// 3. Añadir aristas
grafo.addEdge("A", "B");
grafo.addEdge("B", "C");
grafo.addEdge("C", "A");

// 4. Consultar información
System.out.println("Vértices: " + grafo.vertexSet());
System.out.println("Aristas: " + grafo.edgeSet());
System.out.println("Grado de A: " + grafo.degreeOf("A"));

📦 Tipos de Grafos Disponibles

Clase Descripción Dirigido Ponderado
SimpleGraph Grafo simple sin bucles ni aristas múltiples No No
SimpleDirectedGraph Grafo dirigido simple Sí No
SimpleWeightedGraph Grafo ponderado no dirigido No Sí
SimpleDirectedWeightedGraph Grafo dirigido y ponderado Sí Sí
Multigraph Permite múltiples aristas entre vértices No No
DirectedMultigraph Multigrafo dirigido Sí No
Pseudograph Permite bucles y aristas múltiples No No
